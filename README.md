# Чёткая Линия

Лендинг салона оптики: очки по рецепту, оправы, контактные линзы и детские очковые линзы Stellest. Статический сайт на HTML, CSS и JavaScript.

Сайт: https://hook-atelier.github.io/chetkaya-liniya/

## Локальный просмотр

Из каталога репозитория запустите любой статический HTTP-сервер, например:

```sh
python -m http.server 8080
```

Затем откройте http://localhost:8080/. Сборка и установка зависимостей не требуются.

## Публикация

GitHub Pages: ветка `main`, каталог `/` (корень репозитория). Файл `.nojekyll` отключает обработку Jekyll.

В репозитории находятся только файлы публичного сайта. Локальные материалы разработки и исходные макеты сюда не включены.

Сведения о шрифтах и их лицензии находятся в `assets/fonts/FONT-NOTICES.md` и соседних файлах `OFL-*.txt`.
