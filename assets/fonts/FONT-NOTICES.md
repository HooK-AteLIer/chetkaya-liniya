# Локальные шрифты

В каталоге находятся подмножества Cyrillic и Latin следующих семейств:

- Cormorant Garamond: Cormorant Project Authors. Лицензия SIL Open Font License 1.1, текст в `OFL-Cormorant-Garamond.txt`.
- Manrope: Manrope Project Authors. Лицензия SIL Open Font License 1.1, текст в `OFL-Manrope.txt`.
- JetBrains Mono: JetBrains Mono Project Authors. Лицензия SIL Open Font License 1.1, текст в `OFL-JetBrains-Mono.txt`.

Официальные источники лицензий:

- https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt

Лицензии шрифтов не распространяются автоматически на остальные материалы сайта.
